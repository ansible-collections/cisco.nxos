******************************
cisco.nxos.nxos_netflow_global
******************************

**NetFlow global resource module.**


Version added: 14.1.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- This module manages the global NetFlow configuration of Cisco NX-OS devices, the flow exporters, the flow records, the flow monitors and the flow timeout.
- The assignment of the flow monitors to the interfaces is managed by ``cisco.nxos.nxos_netflow_interfaces``.

Notes
-----

.. note::
   - Tested against NX-OS 10.6(4) on N9K-C93180YC-FX.
   - Unsupported for Cisco MDS.
   - The NetFlow commands only exist when ``feature netflow`` is enabled, use ``cisco.nxos.nxos_feature`` for it.
   - NX-OS 10.6(4) supports only ``version 9`` exporters, no ``sampler`` and no flow monitor cache settings.
   - A flow monitor has two exporters at most and its record can only be replaced, never removed.
   - Settings given with their default value, or a flag given as ``false``, are removed from the device.
   - This module works with connection ``network_cli`` and ``httpapi``.
   - The *parsed* state reads configuration from ``running_config`` and does not connect to the device.

--------

.. code-block:: yaml

    # Using merged

    # Before state:
    # -------------
    # nxos# show running-config | section ^flow
    # nxos#

    - name: Merge the provided configuration with the existing running configuration
      cisco.nxos.nxos_netflow_global:
        config:
          timeout: 30
          exporters:
            - name: EXPORTER1
              description: Collector 1
              destination:
                address: 192.0.2.10
                vrf: management
              source: Ethernet1/1
              transport_udp: 9996
              dscp: 10
              template_data_timeout: 600
              option_exporter_stats_timeout: 300
          records:
            - name: RECORD1
              description: IPv4 flows
              match:
                ipv4:
                  source_address: true
                  destination_address: true
                ip:
                  protocol: true
                transport:
                  source_port: true
                  destination_port: true
              collect:
                counter:
                  bytes: true
                  packets: true
          monitors:
            - name: MONITOR1
              record: RECORD1
              exporters:
                - EXPORTER1
        state: merged
